# Contributing

First open source project. Contributions welcome.

## What to Contribute

**Bug reports**: [Open an issue](https://github.com/hpfrei/body-anatomy-3d-viewer/issues). Say what broke, what browser/OS, how to reproduce it.

**Features**: Got ideas? Open an issue. Measurement tools, annotations, VR, whatever.

**Code**: Fork it, make a branch, test it, open a PR. One feature per PR. Explain what you changed.

**Docs**: Fix typos, clarify stuff. PRs appreciated.

## Setup

```bash
git clone https://github.com/YOUR-USERNAME/body-anatomy-3d-viewer.git
cd body-anatomy-3d-viewer
npx serve -s public -l 3000
```

Everything's in `public/`. No build tools, no dependencies. Change stuff, refresh browser, done.

## Code Style

- Modern JS (ES6+, const/let, arrow functions)
- 4 spaces
- Descriptive names
- Don't overthink it

## Testing

Click around, make sure it works. Test in Chrome/Firefox/Safari if you can.

## Built Something Cool?

If you use `body.glb` in your own project, let me know. You don't need to contribute it back, but if you improve the model itself or viewer code, consider sharing.
